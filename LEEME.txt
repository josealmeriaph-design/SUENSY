SUENSY - versión con registro online conectado a Supabase

Archivos:
- index.html
- manifest.webmanifest
- sw.js
- LEEME.txt

Esta versión conecta el registro e inicio de sesión con Supabase Auth.
La clave incluida es la Publishable key (pública), no una Secret key.
No incluye todavía perfiles compartidos, chat real, pagos, videollamadas ni verificación real de edad.

Para desplegar:
1. Sustituye los archivos del repositorio GitHub por estos.
2. Haz Commit changes en main.
3. Vercel detectará el nuevo commit y publicará una nueva versión.
4. En Supabase, revisa Authentication > URL Configuration y configura Site URL con el dominio real de Vercel, además de Redirect URLs.

La confirmación de correo puede estar activada; el usuario tendrá que confirmar su email antes de iniciar sesión.
